Privacy Policy

Last updated: September 2026

Clip Farm is a personal-use application. It is run locally by its developer and is not distributed to or used by other end users.

Data Collection

This app does not collect, sell, or share personal data belonging to any third party. It only interacts with the developer's own YouTube and TikTok accounts, using API access tokens the developer has personally authorized.

Data Storage

Any access tokens or credentials used by this app are stored locally on the developer's own computer and are not transmitted to any third-party server.

Contact

For questions about this policy, contact the developer directly through the platform's developer portal.
